# Otter support

## Usage questions

Start with the README and the documents in `docs/`. If the documentation does
not answer your question, open a GitHub Discussion when the repository has
Discussions enabled. Otherwise, open an issue only when you can describe a
reproducible documentation or product problem.

## Bugs

Use the bug report template and include:

- Otter version and operating system
- Python and PySide6 versions
- Minimal reproduction steps using fictional data
- Expected and actual behavior
- Sanitized logs or screenshots, when useful

Never upload project archives, credential vaults, customer names, target URLs,
tokens, cookies, passwords, or raw assessment evidence.

## Security vulnerabilities

Do not request security help in a public issue. Follow `SECURITY.md` and use
GitHub Private Vulnerability Reporting when available.
